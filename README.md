# OpenGL Sandbox

A small OpenGL sandbox project used for learning, experimenting, and exploring real-time graphics programming.

The project is primarily based on the concepts and examples from [LearnOpenGL](https://learnopengl.com/), but it also serves as a playground for experimenting with new OpenGL techniques, rendering concepts, and graphics programming ideas.

## Purpose

The main goal of this repository is **learning by doing**.

I use this sandbox to:

* Follow and implement concepts from LearnOpenGL
* Understand how OpenGL and real-time rendering work
* Experiment with different rendering techniques
* Test new ideas before implementing them in larger projects
* Improve my understanding of graphics programming and GPU-based rendering

This is an experimental project, so the code and structure may change frequently as I learn and try new things.

## Technologies

* **C++**
* **OpenGL**
* **GLFW** – window creation and input handling
* **GLAD** – OpenGL function loading
* **GLSL** – shader programming
* **CMake** – build system

## Topics

Some of the topics explored in this repository include:

* OpenGL initialization
* Window and input handling
* Vertex buffers and vertex arrays
* Index buffers
* Shaders
* Textures
* Coordinate systems
* Transformations
* Camera systems
* Lighting
* Materials
  
The exact contents of the repository will evolve over time.


## Building

The project uses CMake.

A typical build can be created with:

```bash
cmake -S . -B build
cmake --build build
```

The exact build configuration may depend on the compiler and platform being used.
